## Панели SM (дополнительно к раскладке)

Панели **не заменяют** модульные выключатели и рамки в таблице выше — это отдельные устройства.

| Помещение | Модель | Статус |
|---|---|---|
| Кухня | **SM08P** | есть |
| Комната | **SM08P** | есть |
| Коридор | **SM10P** | есть |
| *(нужна ещё одна)* | **SM08P** | **купить** |

Итого панелей: **3× SM08P + 1× SM10P**. Осталось купить **1× SM08P**.

## Что купить

### Механизмы

| Позиция | Кол-во |
|---|:-:|
| Розетка силовая (1 пост) | **44** |
| Интернет RJ45 (1 пост) | **3** |
| Выключатель 1-кнопочный | **3** |
| Выключатель 4-кнопочный | **2** |
| **Всего механизмов** | **52** |

### Панели SM

| Позиция | Нужно | Есть | Купить |
|---|:-:|:-:|:-:|
| SM08P | 3 | 2 (кухня, комната) | **1** |
| SM10P | 1 | 1 (коридор) | 0 |

### Рамки

| Рамка | Точки | Где |
|---|:-:|---|
| 1-местная | **10** | лоджия ×2; кладовка выкл.; коридор мастер + свет + туалет + ванна; туалет; холодильник; посудомойка |
| 2-местная | **9** | комната: низ стола, обе кровати, у кладовки; кладовка низ; ванна; кухня: под тумбой, у кровати, плита/духовка |
| 3-местная | **2** | комната за ТВ; кухня за ТВ |
| 4-местная | **2** | комната под ТВ; кухня под ТВ |
| 5-местная | **2** | комната верх стола (планшет); кладовка верх |
| **Всего рамок** | **25** | |

Четырёхкнопочные в коридоре — **1 пост / 1-местная рамка** (один механизм с четырьмя кнопками). Если серия шире — скорректировать по каталогу.

### Подрозетники

Нужно **52** посадочных места (по числу постов).  
Либо 52 одинарных, либо мультибоксы: 10×1 + 9×2 + 2×3 + 2×4 + 2×5.  
Под SM — отдельно, по требованиям монтажа панелей.

### Замечания

- Ванна / туалет у зеркала — розетки с крышкой / IP44 по зоне.
- Холодильник, посудомойка, плита/духовка — отдельные линии; механизмы обычные силовые, рамки как в таблице.
- Серию (Schneider Unica / Gira / Jung / …) в таблице не фиксируем — рамки и механизмы одной линейки.
