Розеточные блоки · JXB-ST-2.5-10pin

Правило: один автомат → одна жила ПУГВ в любую клемму блока → перемычка разводит L на весь блок.
  • Не несколько жил из зажима автомата.
  • Жилые R6 (J1) и стол/ТВ R1 (J5) — один B16: ПУГВ с J1 → J5 (между рейками), не вторая жила с автомата.
  • N/PE по-прежнему каждый кабель в свой ZK — перемычка только L.
