Ключевые правила

Ввод кабелей

  • №1–24 → снизу → рейка R6
  • №25+ → сверху → рейка R1
  • Дальше по щиту только ПУГВ

Вне щита · всё на шину BUSHUB

  • Только RS-485 + 24В → BUSHUB (R1)

Логика сценария

  • Мастер = ON и WB «дома» → MR6CU#2 замкнут → быт питается

  • УЗО6/7 (холод, кондей, WB) живут при отъезде; авария УЗМ гасит и их
