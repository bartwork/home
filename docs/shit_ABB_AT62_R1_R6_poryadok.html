Порядок клемм · рейка R1↑ и R6↓

Слева направо, как смотришь на щит. Маркер = номер кабеля (не позиция). Розеточные L одного автомата — рядом + JXB-ST-2.5-10pin. N/PE в ZK13 — не на этих рейках, кроме синих лок.N рядом с L.

Очередь Ввод R6↓ низ R1↑ верх Втыкай на рейки Таблица кабель→клемма Схема щита Внутри щита

Как ставить

L серая только VPR-2.5-GY · VPRTT не на рейку N синяя лок. VPR-2.5-BU · рядом с L этого кабеля L 6–10 плита / проточный 24В не 230В на DIN

Клеммы узкие (~5 мм). На R6: 23× GY + 1× L6–10 + 4 синих BU. На R1: 33× GY + 1× L6–10 · без BU, потом UTP и BUSHUB. Купить: GY×50 · BU×6 · D-VPR-2.5×20 · JXB-ST-2.5-10pin уп.20. QUATTRO и VPRTT не на рейку. Блоки J1–J6: клеммы на рейки.

Очередь расключения в щите

Если нужен именно порядок работы руками: сначала вводной U-IN, потом низ R6 блоками (техника → J1 → J2), потом верх R1 блоками (J6 → свет → J5 → кухня свет → J3 → сан свет → J4 → люк), и в конце UTP / BUSHUB. №35 не сажать на R1: он идёт на R5: WB-LED как 24В.

Вводной кабель U-IN · не на R1/R6

Excel: вход низ/ввод, жилы L+N+PE, куда ВА50 → УЗМ-50Ц. Серые/синие на R1 и R6 — только уходящие кабели в квартиру. Фабричные N/PE AT62 снять. ВН-102 нет.

L
сразу в ВА50
Фаза → вход ВА-103 2P C50 (`12294DEK`) на R2
Выход ВА50 → вход УЗМ-50Ц. С выхода УЗМ — развилка: ESB и УЗО6/7. УЗМ в силе на весь щит, в катушку ESB не сажать.
N
сразу в ВА50
Ноль → второй полюс ВА50 → УЗМ
С выхода УЗМ: N → ESB 3–4 → N УЗО1…5; отдельно N УЗО6/7. Вводной N не в бытовые ZK144/113/82.
PE
сразу на землю
Земля → магистраль PE → 25 мм² на ZK206G
Схема пишет «питающая PE → 25 мм²» на #1 низ (вход кабеля тоже низ). У #1 есть 6×25: ввод + связь #1↔#2 ПУГВ 10–16 + №7. Корпус AT62 на ту же PE. Не на серую L DIN. U-PE (туалет) — отдельная жила на ту же шину, не ввод.

Сила: U-IN L+N → ВА50 → УЗМ-50Ц → развилка (УЗО6+7 мимо ESB ‖ ESB → УЗО1…5). ВН-102 нет.
