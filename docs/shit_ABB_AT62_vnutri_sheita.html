0. Порядок монтажа внутри щита

Внутренняя сборка щита (не полевые `№1…№105`). Правило рук: сила → нули УЗО в шины → мелочь → поле.

1. Сила (толстое)

  • `U-IN → ВА50 → УЗМ → развилка`
  • Быт: `УЗМ → ESB → УЗО1…5` · EH04 на корпус
  • Always-on: `УЗМ → входы УЗО6 и УЗО7` (не выход в выход)
  • L: УЗО → гребёнки/ПУГВ → автоматы · с УЗО7 ещё D10 / D6 / C2

2. Нули УЗО → шины

  • С выхода N каждого УЗО — один ПУГВ в свой N-блок
  • УЗО7 → шина ↑B «PE DIN + N УЗО7» (3-я справа сверху)
  • N разных УЗО между собой не мостить
  • PE: магистраль с ввода + добор ZK206G / ZK175G

3. Мелочь

  • Катушка: `C2 → MR6CU#2 → A1`; `A2 → шина N УЗО7`
  • `D10 → MORNSUN → UPS → WB7` · MR/MDM/CU с UPS **24В** · MDM#2↔#3 N УЗО4
  • `D6 → ARV` · 24В → WB-LED · RS-485 · EH04→DI
  • `WB7 → BUSHUB` (лучи поля — позже)

4. Поле

  • `shit_ABB_AT62_R1_R6_poryadok.html`
  • №35 = 24В с WB-LED, не 230В
  • BUSHUB → MWAC / M1W2×2 / MSW / ONOKOM×2 / карнизы

0a. С каких выходов куда

Если у аппарата два выхода (L и N) или несколько жил с одного полюса — куда каждая.

УЗМ-50Ц — два выхода (L и N), развилка

ВыходКуда (ветка 1 · быт)Куда (ветка 2 · always-on)
L → вход ESB 1–2 параллельно → входы L УЗО6 и УЗО7
N → вход ESB 3–4 параллельно → входы N УЗО6 и УЗО7

Не соединять выход УЗО6 с выходом УЗО7. Обе always-on ветки — с выхода УЗМ на входы УЗО.

1. Силовая 230В · развилка внутри щита

УЗМ-50Ц в силовом L/N всего щита: `ВА50 → УЗМ → развилка`. В петле A1–A2 УЗМ нет (катушка с УЗО7, уже после УЗМ). N каждого УЗО — на свой ZK (§7). ВН-102 нет.

3. Питание 24В автоматики (внутри щита)

MR6C / MDM3 / MR6CU: питание модуля 24В с UPS (+V/GND). Средний N MR6C пусто. MDM дополнительно L/N 230В своего УЗО. RS-485 от WB7.

4. RS-485 Modbus · две зоны

На шине DIN (WB7)

  • UPS v3 (Modbus слэйв, слева от WB7)
  • MR6C #1–3 · MDM3 #1 (N УЗО1, слева) · MDM3 #2+#3 (N УЗО4, справа)
  • MR6CU #2 (катушка)
  • WB-LED (диммер №35) — DIN после MDM, до D6/ARV

На BUSHUB (поле)

  • MWAC · M1W2×2 · MSW · ONOKOM×2
  • Упр. карнизов Modbus
  • Не сюда: MR/MDM, сила карнизов №34/38

5. Реле MR6C и диммеры MDM3 · внутри щита

MR6C: питание 24В UPS (+V/GND), средний N пусто; коммутирует только L. MDM3: 24В+RS с UPS/WB · L/N 230В — своего УЗО. На R5 порядок: MDM#1 · MDM#2 · MDM#3 — #1 слева (N УЗО1); #2+#3 справа рядом, перемычка N (УЗО4).

7. Шинки N / PE · ZK13 (не на DIN)

Кабель → клемма L на R1/R6 · N → цветной ZK своего УЗО · PE → зелёный ZK. N разных УЗО не мостить. Полная карта как на лице: 4 угла ZK13.
