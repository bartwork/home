Ряд ТП+техника J1 жилые J2 лоджия ZK R6+R1 вместе R1↑ ПУГВ Лицо
Купить на R6: GY×23 · BU×4 (после L №5·6·11·18) · D-VPR торец · JXB-ST-2.5-10pin: J1 = 10pin целиком · J2 = обрезать до 2. №7 = L 6–10. ПУГВ с B16 роз.жилые → в №2; с блока J1 ещё ПУГВ ↑ на J5 (41·43).
Нули ↑ (синие BU): №5·6 ← ПУГВ с УЗО3 · №11·18 → ZK УЗО6. Остальные N — сразу в ZK↓.

Правила ряда

  • Маркер на клемме = номер кабеля. Позиция на рейке = порядок блоков ниже.
  • Серая GY = L → вверх: либо свой ПУГВ на автомат, либо через перемычку JXB.
  • Сразу за L №5·6·11·18 — синяя BU = лок.N.
  • №7 плита — толстая L 6–10 (после синей №6).
  • J1 (10 клемм) = один B16 роз.жилые · перемычка 10pin · одна жила ПУГВ в №2.
  • J2 (19·20) = B16 роз.лоджия · перемычка 2pin · ПУГВ в №19.
