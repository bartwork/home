ISEO дверь схема щита внутри щита автоматы

ISEO · чем открывать и снимать статус из купленного

На DIN уже стоит: WB7 6M → WBIO-DO-SSR-8 (шина WBIO, MQTT EXT1_K*). Открытие — канал SSR · статус — W1 (или DI MR6C). Подробная схема: ISEO дверь.

1. Команда «открыть» — коричневый + синий

По ISEO это оптовход 8–30 В (не сухой контакт сам по себе). SSR замыкает цепь питания команды.

рекомендую питание команды с БП замка (как в мануале ISEO) + канал WBIO-DO-SSR-8:

БП замка +→ коричневый ISEO
синий ISEO→ SSR K1→ БП замка −

Альтернативы: +24В UPS→коричн. / SSR→0В · или Vout WB7→коричн. / SSR→GND (резерв WBMZ4). Не 5Vout. Импульс 1–2 с на EXT1_K1.

Альтернатива: свободный сухой NO канала WB-MR6CU (тот же принцип: 24В → коричн. · синий → NO → 0В). В щите CU уже заняты: №5 сушилка + катушка ESB — бери свободный канал того же модуля или SSR.

2. Статус двери — реле NO + NC

зелёный COM→ GND
оранжевый NO→ W1 / DI = открыто
жёлтый NC→ второй DI = закрыто и сейф

Минимум: зелёный+оранжевый. Жёлтый — явно «закрыто-сейф». БП замка 8–30 В обязателен, иначе реле статуса молчит.

Что не брать под ISEO

  • WB-MCM8 — счётные входы, не статус двери
  • WB-MAO4 / WB-LED / MDM3 — не для замка
  • 5Vout WB7 — ниже нормы 8–30 В, убрать
  • Силовые COM MR6C (230В) — не путать с командой замка

В схеме щита фигурируют MR6CU#1 (сушилка) и MR6CU#2 (ESB), в заказе CU ×1 — второй модуль / каналы уточнить по факту на руках. Для ISEO при наличии WBIO-DO-SSR-8 второй CU не обязателен.

Краткий чеклист ISEO

  1. Снять коричневый/синий с 5Vout / GND
  2. Замок: внешнее питание 8–30 В (кабельный переход)
  3. Открытие: SSR-8 + 24В UPS, импульс 1–2 с
  4. Статус: зелёный→GND, оранжевый→DI MR6C (или W1)
  5. В вебке завести сценарий / MQTT на канал SSR и DI
Жёлтый для статуса не нужен (это NC). Коричневый+синий — только команда, не смешивать со статусом.
