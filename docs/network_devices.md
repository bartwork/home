## Как обновлять реестр

```bash
# кто сейчас в ARP
arp -a | grep '192.168.1.'

# MAC / модель Hikvision
curl -u 'admin:PASSWORD' --digest \
  http://192.168.1.253/ISAPI/System/deviceInfo
```

Правила:
- MAC писать в нижнем регистре, полный вид `aa:bb:cc:dd:ee:ff`
- LAA (второй младший бит первого октета = 1, часто `x2/x6/xa/xe`) — помечать «рандомный MAC», имя уточнять вручную
- Не хранить web/Wi‑Fi пароли в этой таблице
