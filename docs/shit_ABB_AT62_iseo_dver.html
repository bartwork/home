ISEO x1R Smart · дверь через WBIO-DO-SSR-8

На DIN справа от контроллера: WB7 6M (Modbus master / RS-485) → WBIO-DO-SSR-8 (шина WBIO, в MQTT = EXT1_K1…K8). Открытие — сухой SSR · статус реле NO/NC (открыто / закрыто-сейф) · мотор — свой БП.

Важно: коричневый ≠ «просто Vout»

По мануалу ISEO x1R Smart: коричневый (pin 4) и синий (pin 8) — оптоизолированный вход команды, на который нужно подать 8–30 В dc/ac (кнопка / сухой контакт в цепи с этим питанием). Коричневый — не клемма Vout «сама по себе»; это одна нога оптовхода.

Цепь как у ISEO (кнопка = наш SSR):

+ 8…30 В → коричневый → оптовход ISEO → синий → SSR K1 → − того же источника

Откуда брать «+ / −» команды — три рабочих варианта:

Варианткоричневыйсиний через SSR наКогда выбирать
рекомендую C · БП замка + того же БП, что красный − того же БП (чёрный) как пишет ISEO («можно один БП на замок и команду»); SSR реально сухой, развязка чистая
B · шина 24 В +24 В UPS / LI60 0 В той же шины как в заказе WB
A · Vout WB7 Vout WB7 GND WB7 только если нужен резерв команды от WBMZ4 (~11 В, ещё в норме 8–30). Не путать с 5Vout!

Раньше в схеме стоял вариант A как единственный — это было упрощение. Электрически верно, но не единственно верно.

Что приходит с двери в щит

Кабель ISEO 8-пин. Ниже — раскладка для варианта C (БП замка + SSR):

Реле статуса ISEO (сухие контакты, ≤30 В / 1 А): дверь закрыта и сейф (ригели выдвинуты) → реле неактивно → NC замкнут (жёлтый↔зелёный), NO разомкнут. Дверь открывается / открыта → реле активно → NO замкнут (оранжевый↔зелёный), NC разомкнут.
На SSR-8 с двери — только синий (команда). Статус (зелёный / оранжевый / жёлтый) — на DI контроллера, не на SSR.

Минимум хватает одной пары: зелёный+оранжевый на W1 («1 = открыто», «0 = закрыто»). Жёлтый — если нужно явно видеть «закрыто и сейф» отдельным входом (или контроль обрыва линии статуса).

Открытие через WBIO-DO-SSR-8 / EXT1_K1, не через A1. Статус — отдельное реле: можно снять и «открыто» (NO), и «закрыто-сейф» (NC).

Настройки в веб-интерфейсе

  • WBMZ4: Настройки → модули расширения → источник резервного питания = WBMZ4-BATTERY → Записать
  • SSR-8: должен появиться как EXT1_K1…K8 в /devices/wb-gpio/ (уже есть в снимке MQTT)
  • W1: DI ← оранжевый (открыто)
  • Второй DI (MR6C и т.п.): ← жёлтый (закрыто и сейф), опционально
  • Сценарий «открыть»: импульс 1–2 с на EXT1_K1, потом off
  • В Argo реле можно оставить режимом Door status (не Single pulse)
  • UPS v.2: выход с АКБ лучше ~22 В
5Vout не использовать. Белый свободен. SSR K2…K8 — запас.
Без питания мотора (красный/чёрный) WB только замкнёт оптовход — ригели не поедут.
