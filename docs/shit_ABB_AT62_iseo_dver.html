ISEO x1R Smart · кабели двери на WB7

Питание автоматики: сеть → LI60 → WB-UPS → WB7; при отказе UPS — WBMZ4-BATTERY внутри контроллера. Открытие A1 · статус W1 · мотор замка на своём БП.

заказ WB схема щита внутри щита

Порядок резерва (автоматика / команда «открыть»)

  1. Сеть → LI60-20B24 → Vin WB-UPS → Vout 24В → Vin WB7 (+ шина модулей)
  2. Пропала сеть → UPS на своей АКБ (~22 В на v.2) → WB7 и A1 ещё работают → импульс «открыть» жив
  3. Сел / отвалился UPS → WBMZ4 держит только WB7 (~11 В на Vout) → команда ещё возможна, если «+» команды брать с Vout WB7
Мотор замка (красный/чёрный) — не с UPS/WBMZ4. Свой БП 8–30 В + батареи в двери. Без питания замка WB только «щёлкнет» оптовход, ригели не поедут.

Коричневый с Vout (не напрямую с клеммы UPS): тогда при отказе UPS команда ещё питается от WBMZ4 (~11 В). Общий GND обязателен между Vout/GND и синим через A1.

Настройки в веб-интерфейсе

  • WBMZ4: Настройки → модули расширения → источник резервного питания = WBMZ4-BATTERY → Записать
  • W1: режим дискретного входа (не 1-Wire), если термометры идут через M1W2
  • A1: выход OC включён только на время импульса
  • UPS v.2: переключатель выхода с АКБ лучше в положение ~22 В (под 24В шину)
SSR-8 для двери не нужен. 5Vout не использовать. Белый/жёлтый свободны.
