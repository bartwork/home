ABB AT62 · от автоматов куда идёт ПУГВ (L)

С выхода каждого 1P-автомата — куда тянуть фазный ПУГВ. N полевых кабелей на эту страницу не относятся (→ ZK своего УЗО). Вход автоматов с гребёнки куста УЗО — см. выходы УЗО.

Как читать

Три типа выхода L с автомата:
  • прямо — ПУГВ на L-клемму R1/R6 (серая GY / толстая 6–10). Потом полевой кабель.
  • реле — ПУГВ на общий C MR6C (или канал), с канала K → ПУГВ → L-клемма кабеля.
  • диммер — ПУГВ на L 230В модуля MDM / WB-LED, с канала → ПУГВ → L-клемма (или №35 с WB-LED).
прямо без модуля реле MR6C диммер MDM / WB-LED ALW мимо ESB

Один автомат на несколько кабелей: одна жила L с автомата → блок клемм с JXB-ST-2.5-10pin (или вход модуля). Не несколько жил из зажима автомата. Розеточные блоки: см. клеммы на рейки.

Розеточные перемычки JXB-ST-2.5-10pin (уп. 20, обрезать полюса):
  • J1 R6: 2·12·13·14·16·17·21·22·23·24 — 10pin · ПУГВ в №2
  • J2 R6: 19·20 — 2pin · ПУГВ в №19
  • J3 R1: 47·54·55 — 3pin · ПУГВ в №47
  • J4 R1: 63·70 — 2pin · ПУГВ в №63
  • J5 R1: 41·43 — 2pin · питание с J1 (не вторая жила с автомата)
  • J6 R1: 26·105 — 2pin · ПУГВ в №26
